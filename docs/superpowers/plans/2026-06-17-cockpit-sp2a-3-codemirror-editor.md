# Cockpit SP2a-3: CodeMirror-6 Source Editor — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a section-at-a-time CodeMirror-6 SOURCE editor for the proposal in the React SPA at `/cockpit/:id`, wired to the existing byte-stable `save_section` path, with existing citation markers shown as atomic non-typeable pills.

**Architecture:** Two new JSON endpoints live under a new `/api/workspaces/{id}` surface that REUSE the merged `save_section` service and the `/api` ApiError envelope: `GET .../draft` (member-gated; one read returns `head` + `can_edit` + server-split `sections[{index,heading,text,sha}]` + a whole-proposal citation map) and `POST .../sections/{index}` (owner-gated; maps `save_section`'s exceptions to HTTP statuses exactly as the HTMX route does). The frontend mounts a CodeMirror-6 `EditorView` directly (no React wrapper lib), edits RAW `proposal.md` bytes so `sha256(section.text)` is unchanged by construction, and renders full citation markers as `atomicRanges` pill widgets so their bytes stay in the doc. A new SPA route `/cockpit/:id` (distinct from the legacy Jinja `/workspaces/{id}` page, which stays) wires Outline + per-section editor + read-only Full-draft tab.

**Tech Stack:** Backend = Python 3.12 / FastAPI / SQLAlchemy 2.x / pytest+testcontainers / uv / ruff. Frontend = React 18 + Vite + React-Router (data mode) + TanStack-Query + TypeScript + Vitest+jsdom + pnpm (Node 22 via nvm). Editor = CodeMirror 6 (`@codemirror/state`, `@codemirror/view`, `@codemirror/lang-markdown`, `@codemirror/commands`, `@codemirror/language`).

```python
def _seed(app, pg_session_factory, tmp_path, content):
    """Create owner + member + a workspace whose repo holds `content`.

    NOTE: we do NOT override `app.state.session_factory` — create_app() already
    binds it from DATABASE_URL=pg_url (the migrated testcontainers engine), and the

    through the app's own factory both hit one Postgres. This matches the house
    convention in tests/test_api_calls.py / tests/test_api_errors.py.

    with pg_session_factory() as s:
        owner = User(status="active", email="owner@ki.se")
        member = User(status="active", email="member@ki.se")
        stranger = User(status="active", email="stranger@ki.se")
        s.add_all([owner, member, stranger])

def test_draft_returns_server_split_sections_and_head(monkeypatch, pg_url, pg_session_factory, tmp_path):
    app = _app(monkeypatch, pg_url, tmp_path)
    owner_id, _, _, ws_id = _seed(
        app, pg_session_factory, tmp_path, "preamble\n\n## Methods\noriginal.\n"
    )
    c = _client(app, owner_id)
    r = c.get(f"/api/workspaces/{ws_id}/draft")
    assert r.status_code == 200
    body = r.json()
    assert body["can_edit"] is True
    assert isinstance(body["head"], str) and len(body["head"]) == 40
    # Server split: preamble (index 0) + Methods (index 1). Byte round-trip.
    sections = body["sections"]
    assert [s["index"] for s in sections] == [0, 1]
    assert sections[0]["heading"] == ""
    assert sections[1]["heading"] == "Methods"
    assert "".join(s["text"] for s in sections) == "preamble\n\n## Methods\noriginal.\n"
    # sha is sha256 of the section text bytes (64 hex chars).
    assert all(len(s["sha"]) == 64 for s in sections)
    assert body["citations"] == {}
```

```python
"""SP2a-3 cockpit JSON surface: the React source editor's read + save endpoints.

Mounted under /api/workspaces/{id}. Reuses the merged save_section write path
and the proposal_assist permission guards + sectionizer + citation readers.
The runtime error envelope is produced by the global HTTPException handler
(handlers just raise HTTPException); ApiError is the OpenAPI schema mirror.
"""

from __future__ import annotations

import uuid

from fastapi import APIRouter, Depends, HTTPException, Request
from pydantic import BaseModel

from call_manager.auth.dependencies import get_current_user
from call_manager.db.models import Reference, User
from call_manager.proposal_assist.citations import reader as citation_reader
from call_manager.proposal_assist.citations.gitio import GitCommitError, current_head
from call_manager.proposal_assist.citations.ledger import find_by_id, load_ledger
from call_manager.proposal_assist.citations.markers import find_markers
from call_manager.proposal_assist.editing.save import (
    CITATIONS_FILENAME,
    PROPOSAL_FILENAME,
)
from call_manager.proposal_assist.editing.sectionizer import split_sections
from call_manager.proposal_assist.paths import workspace_repo_dir
from call_manager.proposal_assist.web._perms import require_member

router = APIRouter()


class SectionOut(BaseModel):
    index: int
    heading: str
    text: str
    sha: str


class CitationOut(BaseModel):
    citekey: str
    number: int | None = None
    stance: str | None = None
    title: str | None = None


class DraftOut(BaseModel):
    head: str
    can_edit: bool
    sections: list[SectionOut]
    # ev_id -> citation display fields, computed over the WHOLE proposal.
    citations: dict[str, CitationOut]


def _citation_map(session, settings, workspace_id: uuid.UUID, raw: str) -> dict[str, CitationOut]:
    """Build {ev_id: CitationOut} over the WHOLE proposal `raw`.

    number_by_ev/stance_by_ev are proposal-wide; citekey comes from the marker;
    title is resolved per ev_id via the ledger -> Reference row. A missing or
    corrupt ledger yields an EMPTY map (never raises) — same degrade rule as
    _citation_render_maps_for.
    """
    repo_dir = workspace_repo_dir(settings.workspaces_dir, workspace_id)
    citations_path = repo_dir / CITATIONS_FILENAME
    try:
        ledger = load_ledger(citations_path.read_text() if citations_path.exists() else None)
    except (ValueError, OSError):
        return {}
    number_by_ev = citation_reader.build_citation_numbering(raw, ledger)
    stance_by_ev = citation_reader.build_citation_stances(ledger)
    out: dict[str, CitationOut] = {}
    for m in find_markers(raw):
        ev_id = m["ev_id"]
        if ev_id in out:
            continue
        title: str | None = None
        row = find_by_id(ledger, ev_id)
        if row is not None and row.get("reference_id") is not None:
            try:
                ref_uuid = uuid.UUID(str(row["reference_id"]))
            except (ValueError, TypeError):
                ref_uuid = None
            if ref_uuid is not None:
                ref = session.get(Reference, ref_uuid)
                if ref is not None and ref.workspace_id == workspace_id:
                    csl = ref.csl_json or ref.csl_json_extracted or {}
                    title = ref.title or csl.get("title") or ref.filename
        out[ev_id] = CitationOut(
            citekey=m["citekey"],
            number=number_by_ev.get(ev_id),
            stance=stance_by_ev.get(ev_id),
            title=title,
        )
    return out


@router.get("/workspaces/{workspace_id}/draft", response_model=DraftOut)
def get_draft(
    workspace_id: uuid.UUID,
    request: Request,
    user: User = Depends(get_current_user),  # noqa: B008
) -> DraftOut:
    """One read for the editor + Outline + Full-draft tab + pills. Member-gated."""
    settings = request.app.state.settings
    sf = request.app.state.session_factory
    with sf() as session:
        ws = require_member(workspace_id=workspace_id, user=user, session=session)
        can_edit = ws.owner_id == user.id
        repo_dir = workspace_repo_dir(settings.workspaces_dir, workspace_id)
        proposal = repo_dir / PROPOSAL_FILENAME
        if not proposal.exists():
            raise HTTPException(status_code=404, detail="no proposal.md yet")
        try:
            head = current_head(repo_dir)
        except GitCommitError as e:
            raise HTTPException(status_code=404, detail="no proposal.md yet") from e
        raw = proposal.read_text()
        sections = [
            SectionOut(index=s.index, heading=s.heading, text=s.text, sha=s.sha)
            for s in split_sections(raw)
        ]
        citations = _citation_map(session, settings, workspace_id, raw)
    return DraftOut(head=head, can_edit=can_edit, sections=sections, citations=citations)
```

```python
@router.post("/workspaces/{workspace_id}/sections/{index}", response_model=SaveResultOut)
def post_save_section(
    workspace_id: uuid.UUID,
    index: int,
    body: SaveSectionIn,
    request: Request,
    user: User = Depends(get_current_user),  # noqa: B008
) -> SaveResultOut:
    """Save one section via the single write path. Owner-gated. The endpoint
    owns the transaction: save_section adds rows but does NOT commit, and the
    commit mutex is released by this handler's COMMIT / ROLLBACK."""
    settings = request.app.state.settings
    # Mirror the HTMX route's pre-read 404 (sections.py:73-89, used at
    # sections.py:240): before touching save_section, reject a workspace that
    # has no proposal.md yet OR no git HEAD yet with the SAME user-facing 404 as
    # export_markdown / _read_sections. save_section reads HEAD + proposal.md
    # directly (save.py:168-170) and would otherwise surface a raw
    # FileNotFoundError / GitCommitError (500), not a 404. Cover BOTH the same
    # way _read_sections does: .exists() first, then catch GitCommitError.
    repo_dir = workspace_repo_dir(settings.workspaces_dir, workspace_id)
    if not (repo_dir / PROPOSAL_FILENAME).exists():
        raise HTTPException(status_code=404, detail="no proposal.md yet")
    try:
        current_head(repo_dir)
    except GitCommitError as e:
        logger.warning("workspace %s: git HEAD unavailable (%s)", workspace_id, e)
        raise HTTPException(status_code=404, detail="no proposal.md yet") from e
    sf = request.app.state.session_factory
    with sf() as session:
        ws = require_owner(workspace_id=workspace_id, user=user, session=session)
        try:
            result = save_section(
                session=session,
                workspace=ws,
                user_id=user.id,
                section_index=index,
                new_text=body.content,
                base_commit_sha=body.base_commit_sha,
                base_section_sha=body.base_section_sha,
                workspaces_dir=settings.workspaces_dir,
            )
            session.commit()
        except StaleSectionError as e:
            session.rollback()
            raise HTTPException(
                status_code=409,
                detail="this section changed underneath you — reopen it",
            ) from e
        except SectionStructureError as e:
            session.rollback()
            raise HTTPException(
                status_code=400,
                detail=(
                    "keep the section's ## heading line — removing or "
                    "merging sections is done via chat"
                ),
            ) from e
        except CommitMutexTimeout as e:
            session.rollback()
            raise HTTPException(status_code=503, detail=BUSY_ERROR_MESSAGE) from e
        except GitCommitError as e:
            session.rollback()
            logger.exception(
                "section save failed for workspace %s section %s", workspace_id, index
            )
            raise HTTPException(
                status_code=500, detail="save failed — nothing was written"
            ) from e
        except IndexError as e:
            session.rollback()
            raise HTTPException(status_code=404, detail="no such section") from e
    return SaveResultOut.from_result(result)
```

The global `HTTPException`→envelope handler still emits `{error:{code,message}}` for 503 (via `code_for()` returning the `"error"` fallback). The router-level `responses=` won't DOCUMENT 503 in OpenAPI, but the runtime envelope is correct. Do not add 503 to `STATUS_CODES` (that set is the documented-responses source of truth; this slice is the two endpoints only).

```ts
  y: 0,
  width: 0,
  height: 0,

      onchange: null,

      addEventListener: () => {},
      removeEventListener: () => {},
```

```ts
import { RangeSet, type Range } from "@codemirror/state";
import {
  Decoration,
  type DecorationSet,
  EditorView,
  ViewPlugin,
  type ViewUpdate,
  WidgetType,
} from "@codemirror/view";

// Ported VERBATIM from the backend MARKER_RE
// (src/call_manager/proposal_assist/citations/markers.py:23). A full marker is
// `[@<citekey>]<!-- ev:ev-<>=6 hex> -->`. The `g` flag is required for the
// scanning loop; named groups mirror the Python ones. A hand-typed BARE `[@key]`
// (no ev comment) is intentionally NOT matched, so it stays plain editable text.
export const MARKER_RE =
  /\[@(?<citekey>[A-Za-z0-9_-]+)\]<!-- ev:(?<ev_id>ev-[0-9a-f]{6,}) -->/g;

export type MarkerRange = { from: number; to: number; citekey: string; evId: string };

/** All full-marker spans in `text`, in document order. Pure; no editor state. */
export function markerRanges(text: string): MarkerRange[] {
  const out: MarkerRange[] = [];
  const re = new RegExp(MARKER_RE); // fresh lastIndex per call
  let m: RegExpExecArray | null;
  while ((m = re.exec(text)) !== null) {
    out.push({
      from: m.index,
      to: m.index + m[0].length,
      citekey: m.groups!.citekey,
      evId: m.groups!.ev_id,
    });
  }
  return out;
}

/** The atomic, non-typeable citation pill. Renders the citekey; the ev comment
 *  stays in the underlying doc bytes (this widget only REPLACES the rendering).
 *  `onClick` is wired FOR SP2a-4 select-to-cite — stubbed to no-op here. */
export class CitationWidget extends WidgetType {
  constructor(
    readonly citekey: string,
    readonly evId: string,
    readonly onClick: (citekey: string, evId: string) => void,
  ) {
    super();
  }

  // Two widgets are equal (CM6 reuses the DOM) iff their identity fields match.
  // We deliberately do NOT compare onClick: the live component (Task 6) always
  // passes ONE stable wrapper `(c, e) => onPillClickRef.current?.(c, e)` whose
  // function identity never changes, and the *current* callback is read through a
  // ref at click time. So a changed onPillClick prop need NOT rebuild the pill DOM
  // — comparing only citekey/evId is correct and avoids needless widget churn.
  eq(other: CitationWidget): boolean {
    return other.citekey === this.citekey && other.evId === this.evId;
  }

  toDOM(): HTMLElement {
    const el = document.createElement("span");
    el.className = "cm-citation-pill";
    el.dataset.evId = this.evId;
    el.textContent = `@${this.citekey}`;
    el.setAttribute("role", "button");
    el.setAttribute("aria-label", `citation ${this.citekey}`);
    el.addEventListener("mousedown", (e) => {
      // mousedown (not click) so CM6 doesn't move the caret into the atomic range first.
      e.preventDefault();
      this.onClick(this.citekey, this.evId);
    });
    return el;
  }

  // Block the editor from putting a cursor inside the pill via a pointer event.
  ignoreEvent(): boolean {
    return false;
  }
}

/** Factory: a ViewPlugin that maintains the pill DecorationSet AND registers the
 *  same set as atomicRanges (cursor can't enter; partial edits can't split it).
 *  `onPillClick` defaults to a no-op (SP2a-4 wires real select-to-cite). Builds
 *  from the shared `decoSet` helper (declared below; hoisted) so its placement is
 *  byte-identical to `citationField`. */
export function citationPills(
  onPillClick: (citekey: string, evId: string) => void = () => {},
) {
  return ViewPlugin.fromClass(
    class {
      decorations: DecorationSet;
      constructor(view: EditorView) {
        this.decorations = decoSet(view.state.doc.toString(), onPillClick);
      }
      update(u: ViewUpdate) {
        if (u.docChanged || u.viewportChanged) {
          this.decorations = decoSet(u.view.state.doc.toString(), onPillClick);
        }
      }
    },
    {
      decorations: (v) => v.decorations,
      // Make the same spans atomic so the caret skips them and a partial keystroke
      // can't split a marker (the bytes are preserved; only caret entry is blocked).
      provide: (plugin) =>
        EditorView.atomicRanges.of((view) => view.plugin(plugin)?.decorations ?? RangeSet.empty),
    },
  );
}

/** Build the replace-decoration set over an arbitrary `doc` string. The single
 *  source of truth for pill placement — both the ViewPlugin (`citationPills`) and
 *  the StateField (`citationField`) call this, so their spans are byte-identical. */
function decoSet(
  doc: string,
  onClick: (citekey: string, evId: string) => void,
): DecorationSet {
  const ranges: Range<Decoration>[] = [];
  for (const r of markerRanges(doc)) {
    ranges.push(
      Decoration.replace({
        widget: new CitationWidget(r.citekey, r.evId, onClick),
        inclusive: false,
      }).range(r.from, r.to),
    );
  }
  return RangeSet.of(ranges, /* sort */ true);
}

/** A StateField mirror of the pill decorations used by the unit tests so they can
 *  read the DecorationSet synchronously without a live viewport. It provides BOTH
 *  `decorations` AND `atomicRanges` so a test mounting ONLY `citationField` gets
 *  full atomic-pill behavior (caret skips the marker) deterministically — it does
 *  NOT rely on any undocumented default atomicity of a replace widget. The live
 *  component (Task 6) uses `citationPills()` (the ViewPlugin) instead, which also
 *  provides `atomicRanges` and rebuilds on viewport changes for large docs. */
import { StateField } from "@codemirror/state";

export const citationField = StateField.define<DecorationSet>({
  create: (state) => decoSet(state.doc.toString(), () => {}),
  update: (value, tr) => (tr.docChanged ? decoSet(tr.state.doc.toString(), () => {}) : value),
  provide: (f) => [
    EditorView.decorations.from(f),
    EditorView.atomicRanges.of((view) => view.state.field(f, false) ?? RangeSet.empty),
  ],
});
```

> DESIGN NOTE for reviewers: `citationField` (a StateField) exists so the unit tests can read the `DecorationSet` synchronously — a bare jsdom EditorView has a zero-height viewport, so a `viewportChanged`-driven ViewPlugin may decorate nothing. The field provides BOTH `decorations` AND `atomicRanges`, so the atomic-cursor test (mounting only `citationField`) is deterministic and does NOT depend on any default atomicity of a replace widget. The live editor component (Task 6) uses `citationPills()` (the ViewPlugin) which ALSO provides `atomicRanges` and rebuilds on `viewportChanged` for large documents; both build from the identical `decoSet` helper so placement is byte-identical. (`StateField.provide` may return an array of extensions, so providing two facets from one field is supported.)

```tsx
import { defaultKeymap, history, historyKeymap } from "@codemirror/commands";
import { markdown } from "@codemirror/lang-markdown";
import { Compartment, EditorState, Transaction } from "@codemirror/state";
import { EditorView, keymap } from "@codemirror/view";
import { useEffect, useRef } from "react";

import { citationPills } from "./citations";

// An H2 boundary line, mirroring the backend sectionizer `_H2_RE`
// (src/call_manager/proposal_assist/editing/sectionizer.py:20): "##" not followed
// by "#". Used by the heading-delete client guard.
const H2_LINE_RE = /^##(?!#)/;

/** Pure predicate (also unit-tested directly): would replacing `prev` with `next`
 *  delete a non-preamble section's leading "## " heading line? `requireHeading`
 *  is true for every section EXCEPT the preamble (index 0). Returning true means
 *  the transaction must be REJECTED. Mirrors save_section's SectionStructureError
 *  (save.py:196-208) for the NON-preamble case.
 *
 *  Intentional asymmetry: save_section ALSO 400s the REVERSE for the preamble
 *  (index 0) — a non-empty preamble whose first line IS an H2 (save.py:204-208).
 *  This client guard does NOT block that case (it returns false whenever
 *  requireHeading is false), so typing "## " as the first line of the preamble is
 *  left to the server's authoritative 400. That is a deliberate guard relaxation,
 *  not a correctness gap: the server is the source of truth and byte-stability is
 *  unaffected (no save happens). We do not mirror it client-side to keep the
 *  preamble freely editable until the user actually attempts to save. */
export function blockedByHeadingGuard(prev: string, next: string, requireHeading: boolean): boolean {
  if (!requireHeading) return false;
  const firstLine = next.split("\n", 1)[0] ?? "";
  return !H2_LINE_RE.test(firstLine);
}

export type CodeMirrorEditorProps = {
  value: string;
  onChange: (next: string) => void;
  /** true for a non-preamble section: the leading "## " heading may not be deleted. */
  requireHeading: boolean;
  readOnly?: boolean;
  /** Wired FOR SP2a-4 select-to-cite; defaults to a no-op. */
  onPillClick?: (citekey: string, evId: string) => void;
};

// The `--cm-*` vars below are the existing call-manager (NOT CodeMirror) design
// tokens defined in src/styles/tokens.css (the "cm" prefix is "call-manager" — a
// naming collision with CodeMirror that is purely coincidental). Do NOT redefine
// them and do NOT import tokens.css here: it is loaded globally by the app entry,
// so the running editor resolves them. The vitest tests assert document state +
// contenteditable + decoration ranges, never computed colors, so theme resolution
// is not exercised under jsdom (zero-rect polyfills) — that is fine.
const cmTheme = EditorView.theme({
  "&": {
    backgroundColor: "var(--cm-surface)",
    color: "var(--cm-ink)",
    border: "1px solid var(--cm-border)",
    borderRadius: "8px",
    fontSize: "0.95rem",
  },
  ".cm-content": { caretColor: "var(--cm-primary)", fontFamily: "ui-monospace, monospace" },
  "&.cm-focused": { outline: "2px solid var(--cm-primary-border)" },
  ".cm-citation-pill": {
    backgroundColor: "var(--cm-primary-soft)",
    border: "1px solid var(--cm-primary-border)",
    borderRadius: "4px",
    padding: "0 4px",
    color: "var(--cm-primary)",
    cursor: "pointer",
    whiteSpace: "nowrap",
  },
});

export function CodeMirrorEditor({
  value,
  onChange,
  requireHeading,
  readOnly = false,
  onPillClick = () => {},
}: CodeMirrorEditorProps) {
  const hostRef = useRef<HTMLDivElement | null>(null);
  const viewRef = useRef<EditorView | null>(null);
  const readOnlyComp = useRef(new Compartment());
  // Keep the latest onChange/requireHeading/onPillClick without re-creating the
  // view. The pill widget captures a STABLE wrapper at mount that reads this ref,
  // so a changed onPillClick prop takes effect on the next click with no reconfigure
  // (and so widget eq can safely ignore callback identity — see citations.ts).
  const onChangeRef = useRef(onChange);
  const requireHeadingRef = useRef(requireHeading);
  const onPillClickRef = useRef(onPillClick);
  onChangeRef.current = onChange;
  requireHeadingRef.current = requireHeading;
  onPillClickRef.current = onPillClick;

  // Mount ONCE: build EditorView, destroy on unmount.
  useEffect(() => {
    if (!hostRef.current) return;
    const guard = EditorState.transactionFilter.of((tr) => {
      if (!tr.docChanged) return tr;
      const prev = tr.startState.doc.toString();
      const next = tr.newDoc.toString();
      if (blockedByHeadingGuard(prev, next, requireHeadingRef.current)) {
        return []; // reject the transaction; the heading line must survive
      }
      return tr;
    });
    const view = new EditorView({
      state: EditorState.create({
        doc: value,
        extensions: [
          history(),
          keymap.of([...defaultKeymap, ...historyKeymap]),
          markdown(),
          citationPills((citekey, evId) => onPillClickRef.current?.(citekey, evId)),
          guard,
          cmTheme,
          EditorView.lineWrapping,
          readOnlyComp.current.of([EditorState.readOnly.of(readOnly), EditorView.editable.of(!readOnly)]),
          EditorView.updateListener.of((u) => {
            if (u.docChanged && u.transactions.some((t) => !t.annotation(Transaction.remote))) {
              onChangeRef.current(u.state.doc.toString());
            }
          }),
        ],
      }),
      parent: hostRef.current,
    });
    viewRef.current = view;
    // Expose the view for tests (no behavioral effect in prod).
    const cmRoot = hostRef.current.querySelector(".cm-editor") as
      | (HTMLElement & { __cmView?: EditorView })
      | null;
    if (cmRoot) cmRoot.__cmView = view;
    return () => {
      view.destroy();
      viewRef.current = null;
    };
    // value/readOnly handled by the dedicated effects below. onPillClick needs NO
    // effect: the mounted citationPills wrapper reads onPillClickRef.current, so the
    // latest prop is always invoked on click without reconfiguring the view.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  // Controlled external value: push ONLY when it diverges from the live doc, and
  // mark the transaction `remote` so the updateListener does NOT echo it back via
  // onChange (which would loop).
  useEffect(() => {
    const view = viewRef.current;
    if (!view) return;
    const current = view.state.doc.toString();
    if (value !== current) {
      view.dispatch({
        changes: { from: 0, to: current.length, insert: value },
        annotations: Transaction.remote.of(true),
      });
    }
  }, [value]);

  // Flip read-only without rebuilding the view.
  useEffect(() => {
    const view = viewRef.current;
    if (!view) return;
    view.dispatch({
      effects: readOnlyComp.current.reconfigure([
        EditorState.readOnly.of(readOnly),
        EditorView.editable.of(!readOnly),
      ]),
    });
  }, [readOnly]);

  return <div ref={hostRef} className="cm-editor-host" />;
}
```

> NOTE on the `remote` annotation: `Transaction.remote` is a built-in CM6 annotation. The updateListener filters it out so an externally-pushed `value` does not re-fire `onChange` (avoiding a controlled-component loop). User keystrokes carry no `remote` annotation, so they DO fire `onChange`.

```ts
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";

import { api, unwrap } from "./client";

export type SaveSectionVars = {
  index: number;
  content: string;
  base_commit_sha: string;
  base_section_sha: string;
};

/** GET /api/workspaces/{id}/draft — one read for Outline + editor + pills. */
export function useDraft(id: string) {
  return useQuery({
    queryKey: ["draft", id],
    queryFn: async () =>
      unwrap(await api.GET("/api/workspaces/{workspace_id}/draft", { params: { path: { workspace_id: id } } })),
  });
}

/** POST /api/workspaces/{id}/sections/{index}. Invalidates the draft on success
 *  so the editor + Outline re-read the committed bytes. A 409 throws an ApiError
 *  with code "conflict" — the caller (Task 8) catches it to drive the
 *  buffer-preserving conflict prompt (Reload / Keep editing). */
export function useSaveSection(id: string) {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: async (vars: SaveSectionVars) =>
      unwrap(
        await api.POST("/api/workspaces/{workspace_id}/sections/{index}", {
          params: { path: { workspace_id: id, index: vars.index } },
          body: {
            content: vars.content,
            base_commit_sha: vars.base_commit_sha,
            base_section_sha: vars.base_section_sha,
          },
        }),
      ),
    onSuccess: () => qc.invalidateQueries({ queryKey: ["draft", id] }),
  });
}
```

```tsx
import { useQueryClient } from "@tanstack/react-query";
import { useState } from "react";
import { useParams } from "react-router-dom";

import { ApiError } from "../api/client";
import { useDraft, useSaveSection } from "../api/editor";
import { CodeMirrorEditor } from "../editor/CodeMirrorEditor";

type Tab = { kind: "section"; index: number } | { kind: "full" };

export function Cockpit() {
  const { id = "" } = useParams();
  const qc = useQueryClient();
  const draft = useDraft(id);
  const save = useSaveSection(id);
  // PER-SECTION dirty buffers: edits to one section survive switching to another
  // section or to the Full-draft tab and back. A section is dirty iff it has an
  // entry here that differs from the fetched text (see isDirty).
  const [buffers, setBuffers] = useState<Record<number, string>>({});
  // Remember the last section we were on so returning from Full draft restores it
  // (spec line 223: preserve the selection across swaps) instead of resetting to 0.
  const [lastSectionIndex, setLastSectionIndex] = useState(0);
  const [tab, setTab] = useState<Tab>({ kind: "section", index: 0 });
  // The section index that 409'd; its banner offers Reload (discard) / Keep editing.
  const [staleSection, setStaleSection] = useState<number | null>(null);

  if (draft.isLoading) return <main aria-busy="true">Loading cockpit…</main>;
  if (draft.isError || !draft.data) {
    return (
      <main role="alert">
        <h1>Could not load this workspace</h1>
      </main>
    );
  }

  const { head, can_edit, sections } = draft.data;
  const fullText = sections.map((s) => s.text).join("");

  // The active section + its editor value. For the current section we prefer its
  // in-flight buffer over the fetched text; once the buffer is cleared (after a
  // successful save or a Reload) we fall back to the fetched/served text — which is
  // what makes the conflict "Reload" affordance actually reload (Codex #3).
  const activeIndex = tab.kind === "section" ? tab.index : -1;
  const activeSection = activeIndex >= 0 ? sections[activeIndex] : undefined;
  const editorValue =
    tab.kind === "full"
      ? fullText
      : (buffers[activeIndex] ?? activeSection?.text ?? "");

  const isDirty = (idx: number) =>
    buffers[idx] !== undefined && buffers[idx] !== sections[idx]?.text;

  // Switch the CURRENT section only. MUST NOT clear other sections' buffers — their
  // unsaved edits survive (Codex #2). The conflict banner is per-section, so clear it.
  function selectSection(index: number) {
    setTab({ kind: "section", index });
    setLastSectionIndex(index);
    setStaleSection(null);
  }

  function onEditorChange(next: string) {
    if (activeIndex < 0) return;
    setBuffers((b) => ({ ...b, [activeIndex]: next }));
  }

  // Discard this section's edits and show the freshly-fetched/served text. Clearing
  // the buffer makes editorValue fall back to draft text (so the editor visibly
  // reloads — fixing the inert reload), and the refetch pulls the latest server bytes.
  function reloadSection(index: number) {
    setBuffers((b) => {
      const next = { ...b };
      delete next[index];
      return next;
    });
    setStaleSection(null);
    void draft.refetch();
  }

  async function onSave() {
    if (!activeSection) return;
    const index = activeSection.index;
    const content = buffers[index] ?? activeSection.text;
    try {
      const result = await save.mutateAsync({
        index,
        content,
        base_commit_sha: head,
        base_section_sha: activeSection.sha,
      });
      // Optimistically reconcile the cache for THIS section from the save response
      // (head + section_sha; Task 2 dependency) BEFORE clearing the buffer, so the
      // editor never flashes the pre-save draft.data while a refetch is in flight,
      // and the next edit's anti-clobber base is correct (Codex #3).
      qc.setQueryData(["draft", id], (prev: typeof draft.data | undefined) => {
        if (!prev) return prev;
        return {
          ...prev,
          head: result.head,
          sections: prev.sections.map((s) =>
            s.index === index ? { ...s, text: content, sha: result.section_sha } : s,
          ),
        };
      });
      setBuffers((b) => {
        const next = { ...b };
        delete next[index];
        return next;
      });
      setStaleSection(null);
    } catch (e) {
      if (e instanceof ApiError && e.code === "conflict") {
        // Spec line 194: a stale save must NEVER drop the user's buffer. Keep it and
        // prompt; "Reload" discards, "Keep editing" dismisses (re-save re-conflicts
        // until reloaded).
        setStaleSection(index);
      } else {
        throw e;
      }
    }
  }

  // select-to-cite is SP2a-4: wire the callback but no-op it here.
  const onPillClick = (_citekey: string, _evId: string) => {
    /* SP2a-4 */
  };

  return (
    <main className="cockpit">
      <nav aria-label="Outline">
        <ul>
          {sections.map((s) => (
            <li key={s.index}>
              <button
                type="button"
                aria-current={tab.kind === "section" && tab.index === s.index}
                onClick={() => selectSection(s.index)}
              >
                {(s.heading || "preamble") + (isDirty(s.index) ? " •" : "")}
              </button>
            </li>
          ))}
        </ul>
      </nav>

      <section className="cockpit-main">
        <div role="tablist" aria-label="View">
          <button
            type="button"
            role="tab"
            aria-selected={tab.kind === "section"}
            onClick={() => selectSection(lastSectionIndex)}
          >
            Section
          </button>
          <button
            type="button"
            role="tab"
            aria-selected={tab.kind === "full"}
            onClick={() => setTab({ kind: "full" })}
          >
            Full draft
          </button>
        </div>

        {staleSection !== null && (
          <p role="alert">
            This section changed underneath you. Your edits are kept.{" "}
            <button type="button" onClick={() => reloadSection(staleSection)}>
              Reload (discard my edits)
            </button>{" "}
            <button type="button" onClick={() => setStaleSection(null)}>
              Keep editing
            </button>
          </p>
        )}

        {/* ONE persistent EditorView across tab swaps — no `key` remount. The
            controlled `value` effect swaps section bytes and the readOnly
            Compartment (Task 6) flips edit/read-only, so the EditorView instance
            (and its scroll container) survives Section<->Full-draft swaps; the
            restored lastSectionIndex preserves which section you return to
            (spec line 223). */}
        <CodeMirrorEditor
          value={editorValue}
          onChange={tab.kind === "full" ? () => {} : onEditorChange}
          requireHeading={tab.kind === "section" && activeIndex > 0}
          readOnly={tab.kind === "full" || !can_edit}
          onPillClick={onPillClick}
        />

        {can_edit && tab.kind === "section" && (
          <button
            type="button"
            onClick={onSave}
            disabled={save.isPending || !isDirty(activeIndex)}
          >
            Save section
          </button>
        )}
      </section>
    </main>
  );
}
```
