# Digest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the weekly email digest. For each subscribed user, build per-profile buckets (must-include / top-5 / borderline 5), deduplicate across profiles, render an HTML+text email, send via Resend with SMTP fallback, log to `digest_runs`. Track bounces and auto-disable digests for users after 3 consecutive failures. Add the per-user `Hide` button so the digest and feed respect dismissals. Wire it to APScheduler so it fires Monday 07:00 Europe/Stockholm. After this plan ships, the spec's v1 scope is complete.

**Architecture:** New `digest/` module exposes `assemble_for_user(user_id, *, now) → DigestPayload | None` (no DB writes) and `run_digest(*, now) → DigestRunSummary` (the orchestrator that sends and writes). A separate `email/` module wraps the SMTP/Resend send into an `EmailClient` Protocol so the digest module is transport-agnostic. The `Hide` button is a POST handler in `web/routes/calls.py` that inserts into `user_call_dismissals`; the existing dashboard query gains a `NOT IN` clause.

**Tech Stack:** Python 3.12 · FastAPI · Jinja2 (for HTML email templates — MJML deferred, see design decisions) · SQLAlchemy 2.x · Alembic · `httpx` (for Resend) + stdlib `smtplib` (for SMTP fallback) · APScheduler · `pytest` + `testcontainers[postgres]` · Plans 1–4 modules

## Design decisions (fix-now; push back if you disagree)

- **Email transport: Resend HTTP first, SMTP fallback via env config.** `EMAIL_TRANSPORT=resend|smtp` (default `resend`). `RESEND_API_KEY` for the HTTP path; `SMTP_HOST/PORT/USER/PASSWORD/FROM` for the fallback. The hospital ops team can flip the env var without a code change. We do not implement both at once internally — the path is chosen at app startup.
- **No MJML toolchain.** The spec mentions MJML→HTML, but pulling in a Node build step for a single email template is heavy for v1. We hand-write a small Jinja HTML template with inline-style CSS plus a parallel `.txt` template. Resend renders both. If/when designers want richer markup, a future plan can add MJML compilation.
- **Bounce detection is synchronous-only for v1.** Resend's API returns 4xx/5xx for permanent address errors (`invalid_email`, `unknown_recipient`, etc.); we count those as bounces. **Async webhook bounces** (delivered then rejected later) would require a public webhook endpoint and signature verification — out of scope for v1. After 3 consecutive synchronous failures we set `users.digest_bounce_count` (new column) and `users.digest_disabled_at`; admin gets a row in the admin panel rather than an email (alerting infra is a separate plan).
- **`digest_runs.included_call_ids` is plain `int[]`.** Spec line 139 acknowledges this is fine for v1; future per-call audit can migrate to a join table.
- **Cadence: APScheduler `digest:weekly` cron job, Monday 07:00 Europe/Stockholm.** Same single-instance constraint as ingestion/ranking. Dev-mode override via `DIGEST_DRY_RUN=1` (logs payloads without sending) so you can hand-fire the job without spamming people.
- **Hide button writes one row to `user_call_dismissals`.** The dashboard query (Plan 3) gains `AND call_id NOT IN (SELECT call_id FROM user_call_dismissals WHERE user_id = :u)`. The digest assembler does the same. No undo button in v1 (a hidden call returns only via DB intervention) — out of scope.
- **Digest dedup tie-breaker: lowest `profile_id` wins.** Per spec line 420, this keeps the "primary" profile assignment stable across re-ranks.
- **No "nothing to report" emails.** Per spec line 421, if all buckets are empty for every subscribed profile, no email and no `digest_runs` row.
- **`run_digest` is idempotent within a single calendar week per user.** If the scheduler fires twice on a Monday (e.g., a manual run after a code restart), the second run sees the first's `digest_runs` row and skips that user. Implemented as `WHERE NOT EXISTS (SELECT 1 FROM digest_runs WHERE user_id = :u AND sent_at >= date_trunc('week', :now))`.
- **Per-recipient try/except** so one bounce doesn't kill the batch (spec line 438).

```python
@router.post("/calls/{call_id}/hide")
def hide_call(
    request: Request,
    call_id: int,
    user: User = Depends(get_current_user),  # noqa: B008
):
    session_factory = request.app.state.session_factory
    with session_factory() as session:
        if session.get(Call, call_id) is None:

        # ON CONFLICT DO NOTHING — idempotent if user clicks Hide twice

            .values(user_id=user.id, call_id=call_id)
            .on_conflict_do_nothing(index_elements=["user_id", "call_id"])
        )
        session.commit()
    return RedirectResponse(url="/", status_code=303)
```

```python
from __future__ import annotations

from dataclasses import dataclass
from typing import Protocol

import httpx


class EmailTransportError(Exception):
    """Network or transport-level failure. Caller should NOT count this
    as a bounce — it's batch-wide, not per-recipient."""


@dataclass
class SendResult:
    ok: bool
    message_id: str | None = None
    bounce_reason: str | None = None  # set when ok=False (synchronous bounce)


class EmailClient(Protocol):
    def send(self, *, to: str, subject: str, html: str, text: str) -> SendResult: ...


# Resend HTTP API codes that indicate a permanent ADDRESS-level failure.
# 4xx with one of these "name" values → bounce (don't retry, count it).
# Other 4xx (auth, rate-limit, server-side validation) → transport error
# (don't count, alert). Rate-limit is sender-scoped on Resend; treating it
# as a per-recipient bounce would auto-disable users for our quota issue.
_RESEND_BOUNCE_NAMES = {
    "validation_error",
    "invalid_email",
    "missing_field",
}


class ResendClient:
    """Resend HTTPS client. Auth via Bearer api_key. Posts JSON to /emails."""

    _BASE = "https://api.resend.com"

    def __init__(
        self,
        *,
        api_key: str,
        from_addr: str,
        transport: httpx.BaseTransport | None = None,
        timeout: float = 30.0,
    ):
        self._api_key = api_key
        self._from = from_addr
        self._transport = transport
        self._timeout = timeout

    def send(self, *, to: str, subject: str, html: str, text: str) -> SendResult:
        try:
            with httpx.Client(
                base_url=self._BASE, transport=self._transport, timeout=self._timeout
            ) as client:
                resp = client.post(
                    "/emails",
                    headers={"Authorization": f"Bearer {self._api_key}"},
                    json={
                        "from": self._from,
                        "to": [to],
                        "subject": subject,
                        "html": html,
                        "text": text,
                    },
                )
        except httpx.HTTPError as e:
            raise EmailTransportError(f"resend network error: {e}") from e

        if resp.status_code == 200:
            try:
                data = resp.json()
                return SendResult(ok=True, message_id=str(data.get("id") or ""))
            except ValueError as e:
                raise EmailTransportError(
                    f"resend 200 with non-JSON body: {e}"
                ) from e

        if 400 <= resp.status_code < 500:
            try:
                err = resp.json()
            except ValueError:
                err = {}
            name = str(err.get("name") or "")
            message = str(err.get("message") or "")
            if name in _RESEND_BOUNCE_NAMES:
                return SendResult(
                    ok=False,
                    bounce_reason=f"{name}: {message}" if message else name,
                )
            # 4xx that ISN'T a per-address issue (e.g. auth_error, internal_server_error) → transport
            raise EmailTransportError(
                f"resend {resp.status_code} {name}: {message}"
            )

        # 5xx
        raise EmailTransportError(f"resend {resp.status_code}")
```

```python
import smtplib
from email.message import EmailMessage


class SMTPClient:
    """Stdlib smtplib wrapper. STARTTLS on port 587 by convention.

    Treats per-address SMTPRecipientsRefused as bounces; other smtplib
    exceptions as transport errors."""

    def __init__(
        self,
        *,
        host: str,
        port: int,
        user: str | None,
        password: str | None,
        from_addr: str,
        timeout: float = 30.0,
    ):
        self._host = host
        self._port = port
        self._user = user
        self._password = password
        self._from = from_addr
        self._timeout = timeout

    def send(self, *, to: str, subject: str, html: str, text: str) -> SendResult:
        msg = EmailMessage()
        msg["From"] = self._from
        msg["To"] = to
        msg["Subject"] = subject
        msg.set_content(text)
        msg.add_alternative(html, subtype="html")

        try:
            with smtplib.SMTP(self._host, self._port, timeout=self._timeout) as conn:
                conn.starttls()
                if self._user and self._password:
                    conn.login(self._user, self._password)
                conn.sendmail(self._from, [to], msg.as_string())
        except smtplib.SMTPRecipientsRefused as e:
            # Per-recipient reject — bounce
            details = "; ".join(
                f"{addr}:{code} {msg.decode() if isinstance(msg, bytes) else msg}"
                for addr, (code, msg) in e.recipients.items()
            )
            return SendResult(ok=False, bounce_reason=f"refused: {details}")
        except (smtplib.SMTPException, OSError) as e:
            raise EmailTransportError(f"smtp error: {e}") from e

        return SendResult(ok=True, message_id=None)
```

`assemble_for_user(session, *, user_id, now) → DigestPayload | None` returns `None` if there's nothing to send. Otherwise, for each subscribed (active, digest_enabled) profile, compute three buckets: must-include (unconditional), top (≥60, take 5), borderline (45-59, take 5).
```python
from __future__ import annotations

from collections import defaultdict
from dataclasses import dataclass, field
from datetime import datetime

from sqlalchemy import func, or_, select
from sqlalchemy.orm import Session

from call_monitor.db.models import (
    Call,
    CallRanking,
    DigestRun,
    Profile,
    Subscription,
    User,
    UserCallDismissal,
)

DIGEST_TOP_THRESHOLD = 60
DIGEST_BORDERLINE_LOWER = 45
DIGEST_BUCKET_SIZE = 5


@dataclass
class DigestCallEntry:
    call_id: int
    title: str
    summary: str | None
    deadline: datetime | None
    score: int | None
    rationale: str | None
    url: str
    bucket: str  # "must_include" | "top" | "borderline"
    also_in_profiles: list[str] = field(default_factory=list)


@dataclass
class DigestProfileSection:
    profile_id: int
    profile_name: str
    entries: list[DigestCallEntry]


@dataclass
class DigestPayload:
    user_id: int
    user_email: str
    sections: list[DigestProfileSection]
    total_calls: int


def assemble_for_user(
    session: Session, *, user_id: int, now: datetime
) -> DigestPayload | None:
    """Assemble a digest for the given user. Returns None if nothing to send.

    No DB writes — pure read. The caller (run_digest) writes the digest_runs
    row only AFTER a successful send."""
    user = session.get(User, user_id)
    if user is None or user.digest_disabled_at is not None:
        return None

    # 1. Subscribed active profiles, digest_enabled
    profiles = session.execute(
        select(Profile)
        .join(Subscription, Subscription.profile_id == Profile.id)
        .where(
            Subscription.user_id == user_id,
            Subscription.digest_enabled.is_(True),
            Profile.is_active.is_(True),
        )
        .order_by(Profile.id)  # tie-break ordering for dedup
    ).scalars().all()
    if not profiles:
        return None

    # 2. Exclusion sets
    dismissed_ids = set(
        session.execute(
            select(UserCallDismissal.call_id).where(UserCallDismissal.user_id == user_id)
        ).scalars().all()
    )
    prior_ids: set[int] = set()
    for run in session.execute(
        select(DigestRun.included_call_ids).where(DigestRun.user_id == user_id)
    ).scalars().all():
        prior_ids.update(run or [])

    excluded = dismissed_ids | prior_ids

    # 3. For each profile, build candidate entries (pre-dedup)
    # Track: dict[call_id, list[(profile, bucket, ranking_or_none)]]
    per_call: dict[int, list[tuple[Profile, str, CallRanking | None]]] = defaultdict(list)
    call_objs: dict[int, Call] = {}

    for profile in profiles:
        must_terms = [
            t.lower() for t in (profile.structured.get("must_include") or []) if t
        ]

        # 3a. must-include candidates (any score, any ranking, even unranked)
        # Per spec line 417: match against title, summary, AND keywords.
        # We collapse keywords to a space-joined string and ilike-search;
        # this keeps the SQL simple and lets PG's text matching handle
        # case-insensitivity. The GIN index on keywords is bypassed (full
        # scan), but at v1 corpus size (thousands of calls) this is fine.
        if must_terms:
            keywords_str = func.array_to_string(Call.keywords, " ")
            must_q = (
                select(Call)
                .where(
                    Call.id.notin_(excluded) if excluded else True,
                    or_(Call.deadline.is_(None), Call.deadline > now),
                    or_(*[
                        Call.title.ilike(f"%{t}%")
                        | Call.summary.ilike(f"%{t}%")
                        | keywords_str.ilike(f"%{t}%")
                        for t in must_terms
                    ]),
                )
            )
            for c in session.execute(must_q).scalars().all():
                # need this profile's ranking (if any) for score display
                rk = session.execute(
                    select(CallRanking).where(
                        CallRanking.call_id == c.id, CallRanking.profile_id == profile.id
                    )
                ).scalar_one_or_none()
                per_call[c.id].append((profile, "must_include", rk))
                call_objs[c.id] = c

        # 3b. top candidates: score >= threshold
        top_q = (
            select(Call, CallRanking)
            .join(CallRanking, CallRanking.call_id == Call.id)
            .where(
                CallRanking.profile_id == profile.id,
                CallRanking.score >= DIGEST_TOP_THRESHOLD,
                Call.id.notin_(excluded) if excluded else True,
                or_(Call.deadline.is_(None), Call.deadline > now),
            )
            .order_by(CallRanking.score.desc())
            .limit(50)  # over-fetch; dedup may drop some
        )
        for c, rk in session.execute(top_q).all():
            per_call[c.id].append((profile, "top", rk))
            call_objs[c.id] = c

        # 3c. borderline candidates: 45 <= score < threshold
        border_q = (
            select(Call, CallRanking)
            .join(CallRanking, CallRanking.call_id == Call.id)
            .where(
                CallRanking.profile_id == profile.id,
                CallRanking.score >= DIGEST_BORDERLINE_LOWER,
                CallRanking.score < DIGEST_TOP_THRESHOLD,
                Call.id.notin_(excluded) if excluded else True,
                or_(Call.deadline.is_(None), Call.deadline > now),
            )
            .order_by(CallRanking.score.desc())
            .limit(50)
        )
        for c, rk in session.execute(border_q).all():
            per_call[c.id].append((profile, "borderline", rk))
            call_objs[c.id] = c

    # 4. Dedup: each call lands in exactly one (profile, bucket).
    # Selection rule: highest score wins; tie-break by lowest profile_id;
    # bucket priority must_include > top > borderline.
    _BUCKET_PRIORITY = {"must_include": 0, "top": 1, "borderline": 2}
    primary_assignment: dict[int, tuple[Profile, str, CallRanking | None]] = {}
    secondary_profile_names: dict[int, list[str]] = defaultdict(list)
    for cid, candidates in per_call.items():
        # Pick "primary": min by (bucket priority, -score, profile_id)
        def _key(item):
            prof, bucket, rk = item
            score = rk.score if rk else -1
            return (_BUCKET_PRIORITY[bucket], -score, prof.id)
        candidates_sorted = sorted(candidates, key=_key)
        primary = candidates_sorted[0]
        primary_assignment[cid] = primary
        primary_profile_id = primary[0].id
        for prof, _bucket, _rk in candidates_sorted[1:]:
            if prof.id != primary_profile_id and prof.name not in secondary_profile_names[cid]:
                secondary_profile_names[cid].append(prof.name)

    # 5. Group by primary profile, cap top/borderline buckets at 5 each
    grouped: dict[int, dict[str, list[DigestCallEntry]]] = defaultdict(
        lambda: {"must_include": [], "top": [], "borderline": []}
    )
    for cid, (profile, bucket, rk) in primary_assignment.items():
        c = call_objs[cid]
        entry = DigestCallEntry(
            call_id=cid,
            title=c.title,
            summary=c.summary,
            deadline=c.deadline,
            score=rk.score if rk else None,
            rationale=rk.rationale if rk else None,
            url=c.url,
            bucket=bucket,
            also_in_profiles=secondary_profile_names[cid],
        )
        grouped[profile.id][bucket].append(entry)

    # Sort and cap each profile's buckets
    sections: list[DigestProfileSection] = []
    profiles_by_id = {p.id: p for p in profiles}
    for pid in sorted(grouped, key=lambda p: profiles_by_id[p].name):
        buckets = grouped[pid]
        for bucket_name in ("top", "borderline"):
            buckets[bucket_name].sort(
                key=lambda e: e.score or 0, reverse=True
            )
            buckets[bucket_name] = buckets[bucket_name][:DIGEST_BUCKET_SIZE]
        # must_include kept fully (no cap) since they're the user's escape hatch
        ordered = (
            buckets["must_include"] + buckets["top"] + buckets["borderline"]
        )
        if not ordered:
            continue
        sections.append(
            DigestProfileSection(
                profile_id=pid,
                profile_name=profiles_by_id[pid].name,
                entries=ordered,
            )
        )

    if not sections:
        return None

    total = sum(len(sec.entries) for sec in sections)
    return DigestPayload(
        user_id=user_id,
        user_email=user.email,
        sections=sections,
        total_calls=total,
    )
```

```python
from __future__ import annotations

from datetime import UTC, datetime
from pathlib import Path

from jinja2 import Environment, FileSystemLoader, select_autoescape

from call_monitor.digest.assemble import DigestPayload

_TEMPLATE_DIR = Path(__file__).parent / "templates"


def _days_until(deadline: datetime | None) -> int | None:
    if deadline is None:
        return None
    delta = deadline - datetime.now(UTC)
    return max(0, delta.days)


def _env(autoescape_html: bool) -> Environment:
    env = Environment(
        loader=FileSystemLoader(str(_TEMPLATE_DIR)),
        autoescape=select_autoescape(["html"]) if autoescape_html else False,
        trim_blocks=True,
        lstrip_blocks=True,
    )
    env.globals["days_until"] = _days_until
    return env


def render_html(payload: DigestPayload, *, dashboard_url: str) -> str:
    env = _env(autoescape_html=True)
    return env.get_template("digest.html.jinja").render(
        payload=payload, dashboard_url=dashboard_url
    )


def render_text(payload: DigestPayload, *, dashboard_url: str) -> str:
    env = _env(autoescape_html=False)
    return env.get_template("digest.txt.jinja").render(
        payload=payload, dashboard_url=dashboard_url
    )


def build_subject(payload: DigestPayload) -> str:
    profile_names = ", ".join(sec.profile_name for sec in payload.sections)
    return f"{payload.total_calls} new funding call{'s' if payload.total_calls != 1 else ''} for {profile_names}"
```

```python
from __future__ import annotations

import logging
from dataclasses import dataclass
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

from sqlalchemy import distinct, select

from call_monitor.db.models import DigestRun, Subscription, User
from call_monitor.digest.assemble import assemble_for_user
from call_monitor.digest.render import build_subject, render_html, render_text
from call_monitor.email.client import EmailClient, EmailTransportError

_logger = logging.getLogger(__name__)

BOUNCE_DISABLE_THRESHOLD = 3
_TZ = ZoneInfo("Europe/Stockholm")


@dataclass
class DigestRunSummary:
    users_processed: int = 0
    emails_sent: int = 0
    bounces: int = 0
    transport_errors: int = 0
    users_disabled: int = 0


def _week_start(now: datetime) -> datetime:
    """Stockholm-week start (Monday 00:00 Europe/Stockholm) for the week
    containing `now`.

    Why Stockholm and not UTC: the cadence is "Monday 07:00 Europe/Stockholm"
    (spec line 409). If we computed week_start in UTC, a manual run between
    UTC Sunday 22:00 and UTC Monday 00:00 (= Stockholm Mon 00:00–02:00) would
    fall in the *prior* UTC week and silently re-send a digest the user
    already received at the previous Stockholm-Monday 07:00. Stockholm-week
    aligns the idempotency window with the user's perception of "this week"."""
    local = now.astimezone(_TZ)
    monday_local = local - timedelta(days=local.isoweekday() - 1)
    monday_local = monday_local.replace(hour=0, minute=0, second=0, microsecond=0)
    return monday_local.astimezone(now.tzinfo or _TZ)


def run_digest(
    *,
    session_factory,
    email_client: EmailClient,
    settings,
    now: datetime,
) -> DigestRunSummary:
    """Iterate all subscribed users, assemble + send a digest each.

    `settings` may be the real Settings or any object with `.digest_dry_run`
    and `.admin_dashboard_url` attributes (duck-typed for tests).

    Per-recipient try/except so one bounce doesn't stop the batch.
    """
    summary = DigestRunSummary()
    week_start = _week_start(now)

    # Find users who have at least one subscription AND are not auto-disabled.
    # Skipping disabled users at SQL keeps the `users_processed` metric meaningful
    # — assemble_for_user would also reject them, but we'd inflate the count.
    with session_factory() as session:
        candidate_user_ids = session.execute(
            select(distinct(Subscription.user_id))
            .join(User, User.id == Subscription.user_id)
            .where(User.digest_disabled_at.is_(None))
        ).scalars().all()

    for uid in candidate_user_ids:
        summary.users_processed += 1
        with session_factory() as session:
            # Skip if already sent this week (idempotency)
            existing = session.execute(
                select(DigestRun.id).where(
                    DigestRun.user_id == uid,
                    DigestRun.sent_at >= week_start,
                )
            ).scalar_one_or_none()
            if existing is not None:
                continue

            payload = assemble_for_user(session, user_id=uid, now=now)
            if payload is None:
                continue

            html = render_html(payload, dashboard_url=settings.admin_dashboard_url)
            text = render_text(payload, dashboard_url=settings.admin_dashboard_url)
            subject = build_subject(payload)

            if settings.digest_dry_run:
                _logger.info(
                    "digest.dry_run",
                    extra={
                        "event": "digest_dry_run",
                        "user_id": uid,
                        "to": payload.user_email,
                        "subject": subject,
                        "n_calls": payload.total_calls,
                    },
                )
                continue

            try:
                result = email_client.send(
                    to=payload.user_email, subject=subject, html=html, text=text
                )
            except EmailTransportError as e:
                summary.transport_errors += 1
                _logger.warning(
                    "digest.transport_error",
                    extra={"event": "digest_transport_error", "user_id": uid, "error": str(e)},
                )
                continue

            user = session.get(User, uid)
            if not result.ok:
                summary.bounces += 1
                user.digest_bounce_count = (user.digest_bounce_count or 0) + 1
                _logger.warning(
                    "digest.bounce",
                    extra={
                        "event": "digest_bounce",
                        "user_id": uid,
                        "bounce_count": user.digest_bounce_count,
                        "reason": result.bounce_reason,
                    },
                )
                if user.digest_bounce_count >= BOUNCE_DISABLE_THRESHOLD:
                    user.digest_disabled_at = now
                    summary.users_disabled += 1
                session.commit()
                continue

            # Success
            user.digest_bounce_count = 0
            session.add(DigestRun(
                user_id=uid,
                included_call_ids=[e.call_id for sec in payload.sections for e in sec.entries],
                sent_at=now,
            ))
            session.commit()
            summary.emails_sent += 1

    return summary
```

```python
from dataclasses import dataclass
from datetime import UTC, datetime

import pytest
from sqlalchemy import select

from call_monitor.db.models import (
    Call,
    CallRanking,
    DigestRun,
    Profile,
    ProfileKind,
    Source,
    Subscription,
    User,
    UserCallDismissal,
)
from call_monitor.digest.send import run_digest
from call_monitor.email.client import SendResult


class _RecordingEmail:
    def __init__(self):
        self.calls = []

    def send(self, *, to, subject, html, text):
        self.calls.append({"to": to, "subject": subject, "html": html, "text": text})
        return SendResult(ok=True, message_id=f"msg-{len(self.calls)}")


@dataclass
class _FakeSettings:
    digest_dry_run: bool = False
    admin_dashboard_url: str = "http://app/"


@pytest.fixture()
def now():
    return datetime(2026, 4, 20, 7, 0, tzinfo=UTC)


def test_e2e_two_users_one_dismissed_one_must_include(pg_session_factory, now):
    """Drives the full digest path:
    - Two users
    - User A: subscribes to profile P1 (must_include=['pathology'])
    - User B: subscribes to profile P2 (no must_include); also has a dismissal
    - Two calls: one matches P1's must_include, one is high-scoring for P2
      and dismissed by user B
    Assert: A receives the must-include call; B receives nothing.
    """
    with pg_session_factory() as s:
        ua = User(email="alice@ki.se")
        ub = User(email="bob@ki.se")
        s.add_all([ua, ub])
        s.flush()
        p1 = Profile(
            name="P1", kind=ProfileKind.GROUP, description="", structured={
                "areas": [], "budget_min": None, "budget_max": None,
                "trl_min": None, "trl_max": None,
                "must_include": ["pathology"], "hard_exclusions": [],
            }, created_by=ua.id,
        )
        p2 = Profile(
            name="P2", kind=ProfileKind.GROUP, description="", structured={
                "areas": [], "budget_min": None, "budget_max": None,
                "trl_min": None, "trl_max": None,
                "must_include": [], "hard_exclusions": [],
            }, created_by=ub.id,
        )
        s.add_all([p1, p2])
        s.flush()
        s.add_all([
            Subscription(user_id=ua.id, profile_id=p1.id, digest_enabled=True),
            Subscription(user_id=ub.id, profile_id=p2.id, digest_enabled=True),
        ])
        src = s.execute(select(Source).where(Source.slug == "vinnova")).scalar_one()
        c1 = Call(
            source_id=src.id, external_id="c1", url="https://x/1",
            title="Pathology AI breakthrough", summary="big news",
            published_at=now,
        )
        c2 = Call(
            source_id=src.id, external_id="c2", url="https://x/2",
            title="High-score for P2", published_at=now,
        )
        s.add_all([c1, c2])
        s.flush()
        # Score c2 high for P2; c1 low for both
        s.add(CallRanking(
            call_id=c2.id, profile_id=p2.id, score=85, rationale="r",
            model="gemma4:e4b-q8", prompt_version="v1", ranked_at=now,
        ))
        # Bob dismisses c2
        s.add(UserCallDismissal(user_id=ub.id, call_id=c2.id))
        s.commit()
        ua_id = ua.id
        ub_id = ub.id
        c1_id = c1.id

    email = _RecordingEmail()
    summary = run_digest(
        session_factory=pg_session_factory, email_client=email,
        settings=_FakeSettings(), now=now,
    )

    # Alice gets her must-include call; Bob's only candidate is dismissed.
    assert summary.emails_sent == 1
    assert email.calls[0]["to"] == "alice@ki.se"
    assert "Pathology" in email.calls[0]["subject"]
    assert "Pathology AI breakthrough" in email.calls[0]["html"]
    assert "High-score for P2" not in email.calls[0]["html"]

    with pg_session_factory() as s:
        runs_a = s.execute(select(DigestRun).where(DigestRun.user_id == ua_id)).scalars().all()
        runs_b = s.execute(select(DigestRun).where(DigestRun.user_id == ub_id)).scalars().all()
    assert len(runs_a) == 1
    assert runs_a[0].included_call_ids == [c1_id]
    assert runs_b == []  # bob got nothing — no run logged
```
