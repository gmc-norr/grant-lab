# Profiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the profile CRUD + bootstrap flow. A user enters seed data (a list of ORCIDs or names+affiliations plus optional pasted past grants), the app fetches publications from PubMed, feeds them to Gemma 4 E4B to draft a 1–2 paragraph description and suggest structured fields (areas, TRL, budget range, must_include, hard_exclusions), the user refines the draft on an edit screen and saves, which triggers a 90-day backfill of ranking jobs. `/me` gets a subscriptions panel for per-profile digest opt-in. After this plan ships, hospital researchers can build their own ranking profiles end-to-end via the web UI.

**Architecture:** New `profiles/` module exposes `bootstrap_profile(seed) → DraftProfile` — the only function that touches PubMed and the LLM; profile CRUD and subscription management live in `web/routes/profiles.py` and an extended `me.py`. The Profile SQLAlchemy model was already added in Plan 3; this plan wires the UI around it and adds `subscriptions`. `backfill_profile()` (already shipped in Plan 3) gets called on save so a profile-edit flows through to re-ranking without extra plumbing.

**Tech Stack:** Python 3.12 · FastAPI · Jinja2 + HTMX · SQLAlchemy 2.x · Alembic · `httpx` (PubMed E-utilities, with `MockTransport` for tests) · existing `OllamaClient` · `pytest` + `testcontainers[postgres]` · Plans 1–3 modules (auth, ingestion, ranking, backfill)

---

## Design decisions (fix-now; push back if you disagree)

- **No draft state machine.** `POST /profiles/new` creates a Profile row synchronously (runs PubMed + LLM inline, 10–30 s) and redirects to `/profiles/<id>/edit` for refinement. No separate `is_draft` flag — the profile is usable immediately but users see the edit page for a polish pass.
- **Synchronous bootstrap.** The HTTP request blocks until PubMed + Gemma complete. Deferring to a background job adds state-tracking complexity; at v1 admin-only use this is acceptable. Timeout boundary: 60s total, else partial-result fallback (LLM draft from pasted grants alone).
- **Backfill on save.** `POST /profiles/<id>/edit` calls `backfill_profile()` in-process when `description` or `structured` changed. Idempotent (partial unique index), so safe to over-trigger.
- **`user_call_dismissals` + Hide button deferred to Plan 5** (Digest). They're orthogonal to profiles; Plan 5's digest work will natively include the dashboard polish for them.
- **Permissions:** spec line 324 says "Any logged-in user can create or edit any profile" for v1. We enforce login only — no per-profile ACLs.
- **PubMed rate limit:** 3 req/sec unauthenticated. The bootstrap fetch loop sleeps 350 ms between author lookups.

```python
from __future__ import annotations

from dataclasses import dataclass, field


@dataclass
class Member:
    """One research-group member the bootstrap should pull pubs for.

    Either `orcid` OR `(name, affiliation)` must be set; orcid takes
    precedence. Affiliation matches via PubMed's [ad] field and is fuzzy
    by nature — user reviews the draft, so some imprecision is OK.
    """

    orcid: str | None = None
    name: str | None = None
    affiliation: str | None = None

    def __post_init__(self) -> None:
        if not self.orcid and not (self.name and self.affiliation):
            raise ValueError(
                "Member requires either `orcid` or both `name` and `affiliation`"
            )


@dataclass
class Publication:
    pmid: str
    title: str
    year: int | None = None
    authors: list[str] = field(default_factory=list)


@dataclass
class SeedInput:
    name: str  # profile name, user-visible
    kind: str  # 'org' | 'group' | 'user'
    members: list[Member] = field(default_factory=list)
    pasted_grants: str = ""  # free text — titles + abstracts pasted in by user


@dataclass
class DraftProfile:
    """What bootstrap returns. The web layer persists it as a Profile row."""

    description: str
    structured: dict  # matches Profile.structured shape
    publications_fetched: int
    publications_skipped: int  # members whose PubMed search returned zero
```

```python
from __future__ import annotations

import logging
import time
from dataclasses import dataclass

import httpx

from call_monitor.profiles.seed import Member, Publication

_logger = logging.getLogger(__name__)

_BASE = "https://eutils.ncbi.nlm.nih.gov/entrez/eutils"
_RETMAX = 20  # publications per member; 20 is plenty for bootstrap signal


class PubMedError(Exception):
    """PubMed request failed — bootstrap treats this as partial-failure
    and falls back to pasted grants only."""


class PubMedClient:
    """Thin E-utilities client over esearch + esummary.

    Rate-limit conscious: sleeps `sleep_between_members` seconds between
    each member's query. NCBI permits 3 req/s unauthenticated; 350 ms
    keeps us comfortably under that.
    """

    def __init__(
        self,
        *,
        transport: httpx.BaseTransport | None = None,
        timeout: float = 30.0,
        sleep_between_members: float = 0.35,
    ):
        self._transport = transport
        self._timeout = timeout
        self._sleep = sleep_between_members

    def fetch_publications(self, members: list[Member]) -> list[Publication]:
        """Return all publications across the given members.

        Members with zero results are logged and skipped; HTTP errors
        raise PubMedError (the whole fetch fails, caller decides on
        fallback)."""
        pubs: list[Publication] = []
        with httpx.Client(base_url=_BASE, transport=self._transport, timeout=self._timeout) as client:
            for i, member in enumerate(members):
                if i > 0:
                    time.sleep(self._sleep)
                query = _query_for(member)
                pmids = _esearch(client, query)
                if not pmids:
                    _logger.info(
                        "pubmed.no_results",
                        extra={"event": "pubmed_no_results", "member": _describe(member)},
                    )
                    continue
                for pub in _esummary(client, pmids):
                    pubs.append(pub)
        return pubs


def _query_for(member: Member) -> str:
    if member.orcid:
        # ORCID in PubMed's AUID field. Bare ORCID is the documented
        # term syntax; some indexers also accept orcid:... — the portal
        # treats them equivalently.
        return f"{member.orcid}[AUID]"
    # name + affiliation fallback. [au] is the author field, [ad] the
    # affiliation field. Both are fuzzy by nature.
    return f'{member.name}[au] AND {member.affiliation}[ad]'


def _describe(member: Member) -> str:
    if member.orcid:
        return f"orcid={member.orcid}"
    return f"{member.name} @ {member.affiliation}"


def _esearch(client: httpx.Client, query: str) -> list[str]:
    try:
        resp = client.get(
            "/esearch.fcgi",
            params={
                "db": "pubmed",
                "term": query,
                "retmax": _RETMAX,
                "retmode": "json",
                "sort": "date",
            },
        )
        resp.raise_for_status()
        data = resp.json()
    except httpx.HTTPError as e:
        raise PubMedError(f"PubMed esearch failed: {e}") from e
    except ValueError as e:
        raise PubMedError(f"PubMed esearch returned non-JSON: {e}") from e
    return list(data.get("esearchresult", {}).get("idlist", []) or [])


def _esummary(client: httpx.Client, pmids: list[str]) -> list[Publication]:
    if not pmids:
        return []
    try:
        resp = client.get(
            "/esummary.fcgi",
            params={"db": "pubmed", "id": ",".join(pmids), "retmode": "json"},
        )
        resp.raise_for_status()
        data = resp.json()
    except httpx.HTTPError as e:
        raise PubMedError(f"PubMed esummary failed: {e}") from e
    except ValueError as e:
        raise PubMedError(f"PubMed esummary returned non-JSON: {e}") from e

    result = data.get("result", {})
    pubs: list[Publication] = []
    for pmid in result.get("uids", []):
        rec = result.get(pmid)
        if not isinstance(rec, dict):
            continue
        year = _parse_year(rec.get("pubdate"))
        authors = [
            a.get("name", "")
            for a in rec.get("authors", [])
            if isinstance(a, dict) and a.get("name")
        ]
        pubs.append(
            Publication(
                pmid=str(pmid),
                title=str(rec.get("title") or ""),
                year=year,
                authors=authors,
            )
        )
    return pubs


def _parse_year(pubdate: str | None) -> int | None:
    """PubMed pubdate is like '2024 Jan', '2023', '2024 Dec 15'. Take
    the first 4-digit token."""
    if not pubdate:
        return None
    for tok in str(pubdate).split():
        if tok.isdigit() and len(tok) == 4:
            try:
                return int(tok)
            except ValueError:
                return None
    return None
```

```python
def _pubs_block(publications: list[Publication]) -> str:
    if not publications:
        return "(no publications fetched)"
    lines = []
    for p in publications[:40]:  # cap; 40 is plenty of signal for a v1 draft
        year = f" ({p.year})" if p.year else ""
        lines.append(f"- [{p.pmid}]{year} {p.title}")
    return "\n".join(lines)


def build_bootstrap_messages(
    *,
    profile_name: str,
    kind: str,
    publications: list[Publication],
    pasted_grants: str,
) -> list[dict]:
    system = _SYSTEM_TEMPLATE.format(name=profile_name, kind=kind)
    user = _USER_TEMPLATE.format(
        n_pubs=len(publications),
        pubs_block=_pubs_block(publications),
        grants=pasted_grants or "(none)",
    )
    return [
        {"role": "system", "content": system},
        {"role": "user", "content": user},
    ]


def parse_bootstrap_response(content: str) -> DraftProfile:
    """Parse Gemma's JSON response into a DraftProfile.

    Fields missing from the response get sensible defaults (None for
    numerics, [] for lists, "" for description) — the user can fill
    them in on the edit screen."""
    try:
        data = json.loads(content)
    except ValueError as e:
        raise BootstrapParseError(f"LLM returned invalid JSON: {e}") from e
    if not isinstance(data, dict):
        raise BootstrapParseError("LLM response is not a JSON object")

    description = str(data.get("description") or "")
    structured = {
        "areas": _str_list(data.get("areas")),
        "budget_min": _int_or_none(data.get("budget_min")),
        "budget_max": _int_or_none(data.get("budget_max")),
        "trl_min": _int_or_none(data.get("trl_min")),
        "trl_max": _int_or_none(data.get("trl_max")),
        "must_include": _str_list(data.get("must_include")),
        "hard_exclusions": _str_list(data.get("hard_exclusions")),
    }
    return DraftProfile(
        description=description,
        structured=structured,
        publications_fetched=0,  # caller fills in
        publications_skipped=0,
    )


def _str_list(value) -> list[str]:
    if not isinstance(value, list):
        return []
    return [str(v) for v in value if v]


def _int_or_none(value) -> int | None:
    if isinstance(value, bool):
        return None  # Python quirk: bool subclasses int; reject bools
    if isinstance(value, int):
        return value
    return None
```

```python
from __future__ import annotations

import logging

from call_monitor.profiles.bootstrap_prompt import (
    BootstrapParseError,
    build_bootstrap_messages,
    parse_bootstrap_response,
)
from call_monitor.profiles.pubmed import PubMedClient, PubMedError
from call_monitor.profiles.seed import DraftProfile, SeedInput
from call_monitor.ranking.ollama_client import LLMError, OllamaClient

_logger = logging.getLogger(__name__)


def bootstrap_profile(
    *,
    seed: SeedInput,
    pubmed: PubMedClient,
    ollama: OllamaClient,
) -> DraftProfile:
    """Fetch publications (best-effort) + pasted grants → LLM draft.

    Partial failure semantics: if PubMed is unreachable or all members
    return zero hits, we still call the LLM with empty publications and
    whatever grants text the user pasted. If the LLM itself fails, we
    return an empty-ish DraftProfile so the edit screen has a starting
    point — never throws.
    """
    # 1. PubMed (best-effort).
    publications = []
    publications_skipped = 0
    try:
        publications = pubmed.fetch_publications(seed.members)
    except PubMedError as e:
        _logger.warning(
            "profiles.bootstrap.pubmed_failed",
            extra={"event": "bootstrap_pubmed_failed", "error": str(e)},
        )
    # Count members whose query would have returned zero — this is a
    # rough "how complete is the draft" signal shown on the edit page.
    # With the current batched impl we can't distinguish per-member
    # hits without re-walking, so approximate: if we got zero pubs
    # total but members were provided, that's "all skipped".
    if publications:
        publications_skipped = 0
    elif seed.members:
        publications_skipped = len(seed.members)

    # 2. LLM draft.
    messages = build_bootstrap_messages(
        profile_name=seed.name,
        kind=seed.kind,
        publications=publications,
        pasted_grants=seed.pasted_grants,
    )
    description = ""
    structured: dict = {
        "areas": [],
        "budget_min": None,
        "budget_max": None,
        "trl_min": None,
        "trl_max": None,
        "must_include": [],
        "hard_exclusions": [],
    }
    try:
        envelope = ollama.chat(messages=messages)
        content = envelope["choices"][0]["message"].get("content")
        if content:
            draft = parse_bootstrap_response(content)
            description = draft.description
            structured = draft.structured
    except (LLMError, BootstrapParseError, KeyError, IndexError, TypeError) as e:
        _logger.warning(
            "profiles.bootstrap.llm_failed",
            extra={"event": "bootstrap_llm_failed", "error": str(e)},
        )

    return DraftProfile(
        description=description,
        structured=structured,
        publications_fetched=len(publications),
        publications_skipped=publications_skipped,
    )
```

```python
def _parse_members(orcids: str, names_affiliations: str) -> list[Member]:
    members: list[Member] = []
    for raw in orcids.splitlines():
        orcid = raw.strip()
        if orcid:
            try:
                members.append(Member(orcid=orcid))
            except ValueError:
                pass
    for raw in names_affiliations.splitlines():
        line = raw.strip()
        if not line or "|" not in line:
            continue
        name_part, aff_part = line.split("|", 1)
        name_part = name_part.strip()
        aff_part = aff_part.strip()
        if name_part and aff_part:
            try:
                members.append(Member(name=name_part, affiliation=aff_part))
            except ValueError:
                pass
    return members
```
