# Research notes

A model-routing literature survey and its working log. These are **research
artefacts, not app documentation**: they describe an investigation into
task-aware LLM routing for the proposal-assist UX, and nothing in `src/` reads
them.

They sat at the repository root (`research-log.md`, `research-tree.yaml`,
`literature/survey.md`) where they read as project-level files — review
2026-09-02 §12 asked for them to move here.

| File | What it is |
|---|---|
| `model-routing-survey.md` | The survey itself, with its review protocol. |
| `research-log.md` | Dated log of survey phases. |
| `research-tree.yaml` | Machine-readable topic tree for the survey. |
